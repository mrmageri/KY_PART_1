# K-Y-part-1

Эмулятор консоли на Java со Swing-интерфейсом.

## Возможности
- Команды: `ls`, `cd`, `exit`
- Отображение текущего пользователя и хоста

## Требования
- JDK 21+

## Примеры работы
Эмулятор - roman@DESKTOP-ABC:

ls
Command Error!

ls "Моя папка файл.txt"
ls Моя папка файл.txt

cd /home/user
cd /home/user

cd "Моя папка"
cd Моя папка

unknown
Error: command 'unknown' not found.

exit
